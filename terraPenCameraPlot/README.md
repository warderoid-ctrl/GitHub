# terraPen Camera Plot

Phone camera → pen-plotter line art → SVG.

Open `index.html` over HTTPS (e.g. GitHub Pages), allow the camera, pick a style (Waves, Hatch, Spiral, Dots), tune the sliders, then **Save SVG**. Output is sized in millimetres for the chosen paper; hatch layers export as separate Inkscape layers (one per pen).

Inspired by mitxela/plotterfun.
